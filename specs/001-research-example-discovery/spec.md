# Feature Specification: トップページの研究例から研究室を探す

**Feature Directory**: `specs/001-research-example-discovery`
**Issue**: [#15 トップページの研究例から研究室を探せるようにする](https://github.com/mote24405-coder/shiga-lab-recommend/issues/15)
**Created**: 2026-11-25
**Status**: Draft — 要件対話を終え、内容確認待ち
**Input**: 研究分野をまだ絞れていない学生が、修士論文の研究例を眺めて興味を見つけ、研究室へ進む。

## 利用者の目的

学生は最初から研究分野や手法の名前を選ばず、実際に行われた研究を読んで関心のある研究室を見つけたい。トップページに研究テーマの異なる[研究例](../../GLOSSARY.md)を並べる。

## User Scenarios & Testing

### User Story 1 — トップページで研究例に出会う (P1)

学生はトップページで異なる研究テーマの例を見比べる。正式な論文タイトルと日本語要約から興味を持った研究例を選び、その論文を掲載した研究室のページを開く。

**Independent Test**: トップページから研究例を一つ選び、移動先で選んだ論文と研究室のほかの研究を確認する。

**Acceptance Scenarios**

1. 研究室と要約が登録された論文があるとき、学生がトップページを開くと、研究テーマの異なる研究例が6件程度表示される。最初に文章入力やテーマ選択を求めない。掲載可能な論文が6件を超える場合、表示する研究例は固定せず、ページ表示ごとに選び直す。
2. 各研究例には正式な論文タイトルと登録済みの日本語要約を表示し、要約が自動生成されたものであると分かる。
3. 学生が研究例を選ぶと対応する研究室ページへ進み、選んだ論文を見つけられる。同じ研究室のほかの研究も確認できる。

### User Story 2 — さらに研究例を探す (P2)

学生はトップページの例を見た後、「もっと見る」から研究例の一覧を開く。関心のある研究テーマが見つかったら、そのテーマで絞って研究例を探す。

**Independent Test**: 「もっと見る」から一覧を開き、テーマ選択と解除を行い、絞り込んだ研究例から研究室へ進む。

**Acceptance Scenarios**

1. 学生が「もっと見る」を選ぶと、対象の研究例をタイトルと要約で見られる一覧に進める。
2. 一覧を開いた直後はテーマ選択を求めず、複数のテーマの研究例を眺められる。
3. 研究例が1件以上あるテーマから選ぶと、そのテーマに登録された論文の研究例へ絞り込まれる。選択を解除すると、一覧の全対象に戻る。
4. 一つの論文に複数のテーマが登録されている場合、該当するどのテーマからも探せる。一覧で同じ論文を重複表示しない。

### Edge Cases

- 要約がない論文や研究室への対応が未登録の論文は、研究例の画面に掲載しない。既存の修士論文一覧から閲覧できる。
- テーマが未登録の論文でも、要約と研究室への対応があれば、絞り込み前の一覧から探せる。
- 研究例が0件のテーマは一覧の選択肢に表示しない。URLでそのテーマを指定した場合は、結果がないことを示し、テーマ選択を解除できる。
- 掲載可能な研究例が6件に満たない場合は、ある分だけ表示する。
- 論文と研究室の対応が更新された後も、表示中の研究例から別の研究室へ誤って案内しない。

## Requirements

### Functional Requirements

- **FR-001**: トップページに、研究室と日本語要約が登録された実際の修士論文を研究例として表示する。
- **FR-002**: 最初に表示する研究例は6件程度とし、異なる研究テーマに触れられるようにする。研究例の重複を避ける。候補が6件を超える場合は、表示のたびに候補を選び直す。
- **FR-003**: 各研究例に正式な論文タイトルと既存の日本語要約を表示する。要約の文数は制限しない。
- **FR-004**: 日本語要約が論文PDFから自動生成された内容であると、閲覧者に分かるようにする。
- **FR-005**: 研究例を選ぶと対応する研究室ページへ進み、そこで選択した論文を特定できる。
- **FR-006**: トップページから「もっと見る」で、同じ情報を備えた研究例の一覧へ進める。
- **FR-007**: 一覧では研究例が1件以上ある研究テーマによる絞り込みと、その解除ができる。複数テーマを持つ論文は各テーマの結果に含め、同じ一覧内では重複させない。
- **FR-008**: テーマ未登録の対象論文は、絞り込み前の一覧に含める。
- **FR-009**: 要約や研究室への対応が未登録の論文は、既存の修士論文一覧で閲覧できる。

### Key Entities

- **研究例**: 学生が興味を見つける手がかりとして表示する、実際の修士論文に基づく例。論文タイトル、日本語要約、対応する研究室、登録された研究テーマを持つ。
- **研究テーマ**: 学生が関心のある研究例を探すための分類。研究例には複数のテーマが重なる場合がある。
- **研究室**: 学生が研究例から到達する探索先。関連するほかの論文も確認できる。

## Success Criteria

- **SC-001**: トップページから選んだ研究例について、対応する研究室ページで同じ論文を見つけられる。
- **SC-002**: 掲載可能な研究例が6件以上ある場合、トップページに重複のない研究例が6件程度表示され、複数の研究テーマに触れられる。6件を超える場合は、再読み込みを重ねると表示例が入れ替わる。
- **SC-003**: 一覧で研究例が1件以上ある任意のテーマを選ぶと該当する研究例だけが表示され、解除すると絞り込み前の一覧に戻る。
- **SC-004**: 要約がない論文、研究室に紐づかない論文、テーマがない論文、複数テーマの論文を含む操作例で、上記の掲載・絞り込み条件どおりになる。
- **SC-005**: 研究例に表示した要約の自動生成の表示を確認できる。

## 現状と前提

- 現行のトップページは研究例を表示していない。現行の修士論文一覧はタイトル、年度、著者、ラベル、研究室へのリンクを表示する。研究室ページには登録済みの日本語要約がある。[トップページ](../../app/templates/index.html)・[論文一覧](../../app/templates/theses/index.html)・[研究室ページ](../../app/templates/labs/detail.html)
- 開発用DBでの2026-11-25の読み取り集計では、研究室に紐づく114論文すべてに日本語要約があり、そのうち4件には研究テーマが登録されていなかった。実際に掲載する研究例と要約の読みやすさは、計画・実装時に確認する。公開環境の収録状況は未確認。[集計記録](../../daily_reports/2026-11-25-ddd-reference-guide.md)
- 最初の6件の具体的な選定方法、一覧の並び順、画面幅による配置、長い要約の表示方法は実装計画で決める。
- 推薦機能の改善は後続の課題として扱う。
